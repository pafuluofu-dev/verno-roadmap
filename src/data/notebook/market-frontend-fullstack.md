Разбор всех вакансий hh.ru с frontend-стеком по всем странам на 27 сентября 2026: найдено 1010, после удаления дублей 940. Из них 198 — чистый frontend и 281 — fullstack; остальное — backend, QA и mobile, где frontend упомянут вскользь. Цифры ниже — доля вакансий, где требование упоминается.

> **Коротко.** Frontend требует глубины: TypeScript, вёрстка, тесты, качество кода. Fullstack требует ширины: к React добавляются базы данных, Docker и бэкенд, чаще всего на Node.js, Python или PHP.

- **Фронт:** React 65 %, JavaScript 64 %, TypeScript 60 %, Vue 32 %. Вёрстку просят заметно реже, чем во frontend: CSS 39 %, HTML 35 %.

## Как меняются требования с уровнем

По 479 frontend- и fullstack-вакансиям: junior 37, middle 311, senior 131. Разница между уровнями — не во фреймворках, а в инженерной зрелости: архитектуру упоминают 16 % junior-, 53 % middle- и 70 % senior-вакансий, CI/CD — 19 %, 36 % и 44 %. HTML и вёрстка с уровнем уходят на второй план. В чистом frontend переход middle → senior добавляет тесты (44 → 51 %), code review (49 → 55 %) и микрофронтенды (7 → 19 %).

Middle frontend, 135 вакансий: TypeScript 82 %, React 62 %, code review 49 %, тесты 44 %, оптимизация производительности 33 %, CI/CD 29 %. Ни одна библиотека состояния не набирает и четверти middle-вакансий, лидер — Redux с 23 %.

## Что это значит для плана

- **Отклик — фронтендером** (b-profile, b-apply): вёрстка во frontend ценится почти вдвое выше, чем во fullstack, и это то, что уже есть.
- **Сверх базы рынок просит практики, а не библиотеки:** code review через PR (b-git), тесты (b-testing), производительность (b-perf), CI (b-cicd). Этим middle и отличается от джуна.
- **Fullstack-отклик — только с бэкендом в руках:** SQL (b-sql) стоит в 85 % fullstack-вакансий, Docker (b-docker) — в 56 %. Node выбран верно: он в топе вместе с Python.
- **Библиотеки — вторым эшелоном:** TanStack Query, GraphQL и Storybook — ниша до 13 %; Redux — самая частая библиотека состояния, но и он у middle только 23 %.
- **Джунов мало:** 37 из 479 вакансий, поэтому воронка в b-apply рассчитана на сотню откликов, а не на десять.
